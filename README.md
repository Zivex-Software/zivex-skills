# zivex-skills

Install AI-agent skills, always-on rules, hooks and subagents for .NET modular-monolith
development into Claude Code, Cursor and Codex.

> Status: under construction (Phase 1). Full documentation lands in M5.

```sh
npx zivex-skills init
```

Works with npx, pnpm dlx, bunx and yarn dlx. Requires Node 22+. No telemetry.
